# Basics.Tanlash — 4-amaliy vazifa (C# / .NET 8)

Bitta konsol dasturi, bitta `Program.cs` fayl, bitta `Main` metodi ichida uchta interaktiv vazifa:

| Vazifa | Ishlatilgan konstruksiya |
|---|---|
| 1. Aqlli robot | `switch` expression (`_` default holati) + ternary operator |
| 2. Sehrli do'kon | `if` / `else if` / `else` |
| 3. Trafik yoritgich | ternary operator + `&&` (ketma-ket "yashil"), `\|\|` |

## Ishga tushirish

```bash
dotnet run
```
